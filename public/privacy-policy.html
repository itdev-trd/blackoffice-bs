นโยบายความเป็นส่วนตัว

Besight — ปรับปรุงล่าสุด: 9 กรกฎาคม 2569

Besight เป็นเครื่องมือภายในองค์กร (internal tool) ที่ใช้จัดการและยิงโฆษณาผ่าน Meta Marketing API สำหรับทีมแอดมินของบริษัทเท่านั้น ไม่ได้เปิดให้บุคคลทั่วไปหรือลูกค้าภายนอกใช้งาน

ข้อมูลที่ระบบเก็บและใช้งาน

  • บัญชีผู้ใช้ (อีเมล) ของแอดมินที่ได้รับอนุญาตให้เข้าใช้งานระบบ
  • Facebook Page ID และ Ad Account ID ที่แอดมินเพิ่มเข้าระบบเพื่อใช้ยิงโฆษณา
  • เนื้อหาโฆษณา (ข้อความ รูปภาพ) ที่สร้างขึ้นผ่านระบบ และผลลัพธ์ของแคมเปญ (ยอดใช้จ่าย, จำนวนลีด) ที่ดึงมาจาก Meta Marketing API

วิธีใช้ข้อมูล

ข้อมูลข้างต้นถูกใช้เพื่อวัตถุประสงค์ในการสร้าง จัดการ และวัดผลแคมเปญโฆษณาของบริษัทเท่านั้น ไม่มีการขาย ให้เช่า หรือแบ่งปันข้อมูลนี้แก่บุคคลที่สามเพื่อวัตถุประสงค์ทางการตลาดใดๆ

การจัดเก็บและความปลอดภัย

ข้อมูลถูกจัดเก็บในฐานข้อมูล Supabase ที่มีการควบคุมสิทธิ์การเข้าถึง (Row Level Security) เฉพาะผู้ใช้ที่ล็อกอินในระบบเท่านั้นจึงจะเข้าถึงข้อมูลได้ Access Token ของ Meta Marketing API ถูกเก็บเป็นความลับฝั่งเซิร์ฟเวอร์ (Edge Function secrets) ไม่ถูกเปิดเผยฝั่งไคลเอนต์

การลบข้อมูล

ผู้ดูแลระบบสามารถลบบัญชีผู้ใช้ เพจ หรือบัญชีโฆษณาที่เพิ่มไว้ในระบบได้ตลอดเวลาผ่านหน้า "ตั้งค่า" หากต้องการให้ลบข้อมูลทั้งหมดออกจากระบบ ติดต่อผู้ดูแลระบบของบริษัทโดยตรง
